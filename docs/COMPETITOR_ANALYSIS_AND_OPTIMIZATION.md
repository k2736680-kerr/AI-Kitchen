# AI-Kitchen 竞品对比与优化方案（2026-08-05）

> 目标：对照同类头部 App，找出 AI-Kitchen 当前的功能/体验差距，给出可落地的优化优先级。
> 数据来源：下厨房 / 豆果美食 / 美食杰 / 香哈菜谱（国内三强+），Yummly / Whisk(Google) / SideChef / Mealime / BigOven（国际 AI 类）。

---

## 一、竞品能力速览

**国内（菜谱社区型）**
- **下厨房**：海量 UGC 食谱、强社区互动、视频教程、个性化推荐、购物清单、广告偏多。UI 简洁清新，大图聚焦。
- **豆果美食**：智能搜索/筛选（按食材/做法/低卡）、**营养分析**（热量/蛋白/脂肪/碳水）、食材商城一键购买、社区活动。界面表现最受好评。
- **美食杰**：界面简洁、操作方便、经典菜谱+名家教程、**步骤详解+小贴士**、内置计时器/量具换算、**离线下载**。
- **香哈菜谱**：独家秘制菜谱、步骤详细+烹饪小贴士、支持离线。

**国际（AI 生成/规划型）**
- **Yummly**：AI 学习口味偏好推荐、**按已有食材筛选**、烹饪时间/技能筛选、**分量缩放**、自动购物清单、视觉 feed 布局。
- **Whisk(Google)**：从任意网站一键保存菜谱、AI 识别食材与分量、**图片识别菜品**、免费、购物清单整合配送。
- **SideChef**：**逐步语音引导烹饪**、每步照片/视频、**内置计时器**、智能厨电集成、自动购物清单。新手友好。
- **Mealime**：AI 生成周计划、饮食筛选（素食/keto）、自动购物清单、30 分钟菜谱。
- **BigOven**：**"用剩余食材找菜谱"**（输入 3 种食材即出菜谱）、购物清单、膳食规划。

## 三、AI-Kitchen 现状评估（诚实版）

**已做好（可对外讲的优势）**
1. 食材网格多选 → 通义千问 AI 生成菜谱（核心闭环通）。
2. **多做法候选**是独一无二的差异化点（炒/炖/蒸/汤/凉拌/烤），竞品都没有。
3. 食材大图卡通卡片（16+ 张 AI 生图）、温暖治愈系渐变 UI、暗色模式、中英 i18n。

**明显短板（竞品人人都有，我们没有）**
1. **分量缩放**：选了菜谱却不能改 2 人/4 人，用量不会跟着变 —— 这是最基础的预期功能。
2. **购物清单**：生成的菜谱里哪些家里有、哪些要买，完全没有辅助。
3. **收藏**：历史记录 ≠ 收藏，用户想"存下来以后做"没有入口。
4. **逐步引导计时器**：烹饪步骤卡是静态的，缺少每步倒计时（下厨房/美食杰/SideChef 都有）。
5. **营养信息**：豆果/Yummly 都给热量蛋白，我们没有。
6. **搜索**：首页直接是食材网格，没有"热门+历史搜索"的入口，无目的浏览体验差。
7. **空状态/新手引导**：首次进入没有引导，用户不知道能干嘛。

## 四、优化路线图（按价值/成本排序）

### P0 —— 补齐"基础预期功能"（竞品标配，用户会默认你有）
| 优化 | 说明 | 成本 |
|---|---|---|
| **分量缩放** | 菜谱详情/步骤页加人数选择器（2/4/6 人），用量按比例实时换算 | 中（前端+后端支持比例字段） |
| **收藏** | 与 history 分离，菜谱详情加❤，独立"我的收藏"入口 | 低（加表+接口） |
| **购物清单** | 从菜谱食材清单生成，标记"已有/待买"，可勾选 | 中 |
| **空状态 & 新手引导** | 首页/历史空态给引导文案与操作按钮 | 低 |
| **烹饪计时器** | 步骤卡每步加倒计时（如"焖 5 分钟"可点开计时） | 低 |

### P1 —— 差异化增强（让我们比竞品更聪明）
| 优化 | 说明 | 成本 |
|---|---|---|
| **营养信息** | 生成时一并给热量/蛋白/脂肪，详情页展示 | 中（提示词+展示） |
| **小贴士/注意事项** | 每菜谱生成"成功关键/避坑"区块 | 低（提示词） |
| **个性化推荐 feed** | 首页除食材网格外，加"为你推荐/最近流行" | 中 |
| **按已有食材智能推荐** | 类似 BigOven"用剩余食材找菜谱" | 中（复用生成能力） |

## 五、具体实现要点（结合现有代码）

- **分量缩放**：`recipe` 数据模型增加 `baseServings` 与每食材 `amount`（带单位）；详情页 `recipe-header.tsx` 加 `ServingsSelector`，前端按比例换算展示。后端生成时要求模型给出标准 2 人份用量。
- **收藏**：新增 `favorites` 表（`userId`, `recipeId`, `createdAt`）；`history.tsx` 之外加 `favorites.tsx` 入口；详情页加收藏按钮。
- **购物清单**：基于 `recipe-ingredient-list.tsx` 的食材，让用户勾选"家里有/要买"，本地存储 + 可导出文本。
- **烹饪计时器**：`cooking-step-card.tsx` 解析步骤里的时长（如"5 分钟"），渲染可点击的计时器组件（用 `react-native` 原生 `Timer`/状态管理，无需新依赖）。
- **营养信息**：生成提示词增加营养字段；`recipe-header.tsx` 用现有标签样式展示。
- **空状态**：`index.tsx` / `history.tsx` 加 `EmptyState` 组件（图标+引导文案+按钮）。
